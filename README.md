# Red Topológica Interestelar — prototipo 3D corregido

Esta versión incluye los botones **⚡ Inyectar perturbación** y **Reiniciar simulación** en el panel izquierdo.

## Actualizar la aplicación publicada
1. Descarga y descomprime el ZIP.
2. Abre el repositorio de GitHub donde publicaste la aplicación.
3. Reemplaza el archivo `app.py` anterior por el nuevo `app.py`.
4. Asegúrate de que `requirements.txt` esté en la raíz del repositorio.
5. Guarda con **Commit changes**. Streamlit Community Cloud normalmente volverá a desplegarla automáticamente.

Si no se actualiza, abre el panel de la aplicación en https://share.streamlit.io/ y reiníciala.

Las reglas de propagación son heurísticas para explorar el concepto, no leyes físicas validadas.
